# Academia · sesión 4: Redux Toolkit, RTK Query y login

Código de los apuntes `04_react_redux_toolkit_login.md`.

"Mis cursos" pasa a Redux Toolkit, los datos de la API se piden con RTK Query y hay un login falso con ruta protegida (`/admin`).

```bash
npm install
npm run api     # terminal 1: API en http://localhost:3001
npm run dev     # terminal 2: app en http://localhost:5173
```

Usuarios de prueba (en `db.json`): `admin@academia.es` / `academia123` y `lucia@correo.es` / `lucia123`.

Para dejar los datos como al principio: `cp db.inicial.json db.json`.
